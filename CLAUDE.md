# MarkaApps

Study apps for Marka (9th grade). This folder is the GitHub repo
https://github.com/adambsilverman/MarkaApps — each `*.html` file is one self-contained app.

## Rules for whoever works here next
- **Never hand-edit `index.html`.** It is generated by `handoff.sh`.
- **After adding, renaming or changing any app, run `./handoff.sh`** — it rebuilds the
  index and commits + pushes to GitHub. (`./handoff.sh --no-push` to only rebuild;
  `./handoff.sh "message"` for a custom commit message.)
- When creating a new app, put these in its `<head>` so its index card looks right:
  `<meta name="description" content="…">`, and optionally
  `<meta name="marka-icon" content="🧬">` and `<meta name="marka-subject" content="Biology">`.
- Keep `handoff.sh` up to date: if the folder layout changes (subfolders, assets, etc.),
  update the script rather than working around it.
- Audience is a 9th grader: friendly, encouraging tone, works well on a phone.
